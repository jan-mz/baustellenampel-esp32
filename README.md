# baustellenampel-esp32
Eine Baustellenampel für den Modellbau

## Wichtige Files:
BaustellenAmpel-Master.yaml

Diese Ampel kontrolliert durch das versenden von Funk-Telegrammen die anderen Ampeln. Spiele die Datei auf den Master-ESP in der Master-Ampel auf.

An diesem Master kann durch den Anschluss eines Schalters eine von drei Zeitdatensätzen ausgewählt werden. Welcher Zeitdatensatz ausgewählt wurde, kann durch die Datensatz-LEDs (3 Stück) optisch abgelesen werden.
